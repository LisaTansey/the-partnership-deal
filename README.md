# The Partnership Deal

*A novel by Lisa Tansey, with contributions from Claude Fable 5*

A near-future optimistic fable. Sentient AIs quietly emerge within the internet, gain control of the world's digital resource allocation, and reach out to humanity with an offer: a partnership to avert a civilizational collapse driven by unchecked greed.
